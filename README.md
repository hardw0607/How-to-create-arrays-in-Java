# How to create arrays in Java

// 1. Literal
int[] a = {1, 2, 3};

// 2. With size (defaults to 0)
int[] b = new int[5];        // [0, 0, 0, 0, 0]

// 3. 2D array (array of arrays)
int[][] grid = new int[3][4];   // 3 rows, 4 columns

// 4. Jagged (rows of different lengths)
int[][] jag = {{1,2}, {3,4,5}, {6}};
